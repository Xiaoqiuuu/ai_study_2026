# AI 学习之旅 (2026.07-2026.08)

为 AI 实习准备的为期一个月学习计划，涵盖机器学习、深度学习、LLM 与 Agent 系统。

## 技术栈
- Python / PyTorch / NumPy / Pandas
- Transformers / LangChain / Gradio
- C++ / pybind11

## 项目结构
- `week1_ml/`：机器学习基础 + LLM API 调用
- `week2_dl/`：深度学习 + 手写 Transformer
- `week3_agent/`：RAG 知识库 + ReAct Agent
- `week4_cpp/`：C++ 基础 + 算法题

## 运行环境
- Python 3.10
- PyTorch 2.3.1 (CUDA 12.4)
- RTX 4050 6GB

## 项目亮点
1. **本地 RAG 知识库**：基于 Chroma + Sentence-Transformer 的文档问答系统
2. **ReAct Agent**：支持工具调用的智能 Agent
3. **手写 Transformer**：从零实现 Multi-Head Attention
