> 整理原则：用"自己的话"解释，能对着面试官讲 2-3 分钟不卡壳。

## Day 1：NumPy + 手写线性回归 + 数据预处理

### Q1：什么是广播机制（Broadcasting）？

**答**：NumPy 做运算时，如果两个数组形状不同，它会自动把小的那个"拉伸"成大的形状，让运算能进行。规则是从后往前比维度：要么相等，要么其中一个为 1，否则报错。

**例子**：`(3,1) + (2,)` → `(3,1)` 拉伸成 `(3,2)`，`(2,)` 拉伸成 `(3,2)`，结果 `(3,2)`。

**实际应用**：线性回归中 `X @ w + b`，`b` 是标量，自动广播到所有样本。

---

### Q2：手写线性回归时，梯度下降的核心公式是什么？怎么推导的？

**答**：
- 损失函数：MSE = `1/n * Σ(y_pred - y)²`
- 对 w 求导：`dw = 2/n * X.T @ (y_pred - y)`
- 推导：链式法则。`d(MSE)/dw = 2/n * Σ(y_pred - y) * d(y_pred)/w = 2/n * X.T @ (y_pred - y)`，因为 `y_pred = Xw + b`，所以 `d(y_pred)/dw = X`。

**更新规则**：`w := w - lr * dw`

---

### Q3：为什么线性回归可以用正规方程 `w = (X^T X)^(-1) X^T y`，还要学梯度下降？

**答**：
- 正规方程是解析解，直接算出来，但复杂度 `O(d³)`，特征多的时候算不动。
- 梯度下降是迭代解，复杂度 `O(nd)` 每轮，适合大数据、在线学习。
- 正规方程要求 `X^T X` 可逆，实际中可能病态，需要数值代数技巧（QR/SVD）。

---

### Q4：DataProcessor 里为什么要先 `split` 再 `normalize`？先 `normalize` 有什么问题？

**答**：
- **正确流程**：先划分训练集/测试集 → 用训练集的 mean/std 标准化训练集 → **用同样的 mean/std 标准化测试集**。
- **错误流程**：全部数据一起标准化 → 测试集的统计信息（mean/std）泄露给了训练过程 → 模型评估虚高，实际部署崩掉。
- 这叫**数据泄露（Data Leakage）**，是机器学习工程中的大忌。

---

### Q5：链式调用 `return self` 的设计有什么好处？

**答**：支持 Fluent Interface，代码更简洁。比如 `processor.normalize().split()`，如果 `normalize()` 不返回 `self`，就必须拆成两行写，中间变量暴露，不够优雅。

---

### Q6：双指针相比暴力解法有什么优势？适用场景是什么？

**答**：
- 时间复杂度通常从 `O(n²)` 降到 `O(n)`，空间 `O(1)`。
- 适用场景：**有序数组**（左右指针向中间夹逼）、**原地修改**（快慢指针）、**判断环**（快慢指针）。
- 核心思想：利用数组的单调性或者问题的特定结构，避免重复扫描。

## Day 2：逻辑回归 + 正则化 + LLM Prompt

### Q1：逻辑回归为什么用 Sigmoid？它把什么映射成了什么？

**答**：
- 线性回归输出 `(-∞, +∞)`，但分类需要概率 `(0,1)`。
- Sigmoid：`σ(z) = 1 / (1 + e^(-z))`，把任意实数压到 `(0,1)`。
- 当 `z=0` 时 `σ=0.5`，`z→+∞` 时 `σ→1`，`z→-∞` 时 `σ→0`。

---

### Q2：逻辑回归为什么用交叉熵（Cross Entropy）而不是 MSE？

**答**：两个原因：
1. **非凸性**：MSE + Sigmoid 的组合会导致损失函数非凸，存在大量局部最优，梯度下降容易卡住。
2. **梯度消失**：Sigmoid 两端饱和时（输出接近 0 或 1），MSE 的梯度趋近于 0，参数几乎不更新；交叉熵的梯度是 `(p - y)`，即使饱和也有信号。

---

### Q3：L1 和 L2 正则化的区别？从几何角度解释为什么 L1 产生稀疏解。

**答**：
- **L2（Ridge）**：惩罚项是 `λ/2 * ||w||²`，求导后为 `λw`，大权重受惩罚重，小权重受惩罚轻，所以权重均匀变小，但不会精确为 0。
- **L1（Lasso）**：惩罚项是 `λ * ||w||₁`，求导后为 `λ * sign(w)`（常数），无论权重多大惩罚力度一样，会把小权重直接压到 0。
- **几何解释**：L2 的约束是圆形，最优解在圆周任意位置；L1 的约束是菱形（顶点在坐标轴），最优解容易落在顶点上 → 某些维度恰好为 0 → 稀疏。

---

### Q4：梯度下降和牛顿法的区别？

**答**：
- **梯度下降**：只用一阶导数（梯度），`w := w - lr * ∇f`，简单但收敛慢，需要调学习率。
- **牛顿法**：用二阶导数（Hessian 矩阵），`w := w - H^(-1) * ∇f`，收敛快（二次收敛），但每次算 Hessian 逆矩阵复杂度 `O(d³)`，高维不实用。
- 实际中：梯度下降最常用，牛顿法只在低维或作为思想参考（如 Adam 近似二阶信息）。

---

### Q5：Zero-shot 和 Few-shot Prompt 的区别？为什么 Few-shot 通常更准确？

**答**：
- **Zero-shot**：直接问，不给例子。模型靠预训练知识回答。
- **Few-shot**：给 2-3 个例子，让模型"模仿"格式和逻辑。
- **原理**：Few-shot 不是让模型"理解"规则，而是提供了**条件概率的锚点**。例子中的输入-输出模式诱导模型进入训练数据中相似的概率分布区域，相当于零成本的局部微调。

---

### Q6：为什么 `np.clip` 在 Sigmoid 里是必须的？

**答**：防止数值溢出。当 `z` 是很大的负数（比如 `-1000`）时，`e^(-z) = e^1000` 会超出浮点数上限，变成 `inf`，导致 `1/(1+inf)` 变成 `NaN`。`clip(z, -500, 500)` 把指数限制在安全范围内。

## Day 3：sklearn Pipeline + 随机森林 + 特征工程

### Q1：Pipeline 的作用是什么？为什么它能防止数据泄露？

**答**：
- **作用**：把预处理（标准化、编码）和模型训练串成一条链，像工厂流水线。
- **防泄露原理**：交叉验证的每一折里，Pipeline 会先在**训练集**上 `fit` 预处理参数（如 mean/std），然后用这些参数 `transform` **验证集**。验证集的信息从不参与预处理参数的计算。
- 如果手动先标准化再划分，验证集的统计信息就混进去了，导致评估虚高。

---

### Q2：`ColumnTransformer` 是做什么的？

**答**：对不同类型的特征（数值型、类别型）分别应用不同的预处理流程，最后自动拼接结果。比如数值特征做 `StandardScaler`，类别特征做 `OneHotEncoder`，输出拼成一个大矩阵喂给模型。

---

### Q3：随机森林为什么能降低方差？两重随机性分别指什么？

**答**：
- **降低方差原理**：多棵相关性低的树，通过大数定律平均掉单棵树的随机误差。假设每棵树误差独立，B 棵树的平均方差降为单棵的 `1/B`。
- **第一重随机（样本随机）**：Bootstrap 有放回采样，每棵树训练集不同。
- **第二重随机（特征随机）**：每次分裂只随机选 `k` 个特征（`k=√d`）找最优，而不是全部特征。防止某几个强特征主导所有树，降低树间相关性。

---

### Q4：随机森林的 OOB（Out-of-Bag）评分是什么？为什么不需要单独的验证集？

**答**：
- Bootstrap 采样时，每个样本有约 63.2% 的概率被抽到，36.8% 的概率没被抽到（OOB 样本）。
- 每棵树的 OOB 样本天然可以作为这棵树的验证集。
- 把所有树对各自 OOB 样本的预测聚合，就能得到一个**无偏的泛化误差估计**，不需要单独划分验证集。

---

### Q5：XGBoost 和随机森林的核心区别？

**答**：
- **随机森林**：Bagging，树之间**并行**训练，互相独立，**降低方差**。
- **XGBoost**：Boosting，树之间**串行**训练，每棵树拟合前面所有树的残差（梯度），**降低偏差**。
- 形象比喻：随机森林是"一群人独立投票"，XGBoost 是"前一个人犯错，后一个人专门补这个错"。

---

### Q6：为什么 PCA 不适用于 Titanic 这种低维表格数据？

**答**：
- PCA 的核心价值是**降维**（解决维度灾难），Titanic 只有 ~10-20 个特征，没有维度灾难。
- PCA 会摧毁可解释性：把 `Sex`、`Pclass` 等人类能理解的特征线性组合成"主成分1"，谁也不知道主成分1代表什么。
- PCA 对稀疏的 OneHot 编码效果差，且可能把最强预测信号（如 `Sex`）分散到多个主成分中，反而削弱预测力。
- **低维表格数据的正确优化方向**：特征工程（交互项、分桶、目标编码），而不是降维。

---

### Q7：交叉验证（CV）分数很高，但测试集分数低很多，说明什么？怎么解决？

**答**：
- **说明过拟合**。模型记住了训练集的噪声，泛化能力差。
- **解决**：
  1. 减少模型复杂度（降低多项式次数、限制树深度、增加正则化）。
  2. 增加数据量。
  3. 减少特征数量或做特征选择。
  4. 检查是否有数据泄露（预处理是否先 fit 再 transform）。

---

### Q8：`GridSearchCV` 里的 `cv=5` 是什么意思？`n_jobs=-1` 呢？

**答**：
- `cv=5`：5折交叉验证。数据分成 5 份，轮流用 4 份训练、1 份验证，取 5 次验证分数的平均。
- `n_jobs=-1`：用所有 CPU 核心并行训练，加速搜索。

## 通用工程问题

### Q9：Git 中 `git add`、`git commit`、`git push` 分别做了什么？

**答**：
- `git add`：把工作区的修改放入**暂存区**（Stage）。
- `git commit`：把暂存区的内容正式存档到**本地仓库**，生成一个不可篡改的版本快照。
- `git push`：把本地仓库的新提交上传到**远程仓库**（GitHub），实现备份和协作。

---

### Q10：为什么 `.gitignore` 里要忽略 `.env`、`__pycache__`、模型权重文件？

**答**：
- `.env`：包含 API Key、数据库密码等敏感信息，上传后任何人都能看到。
- `__pycache__`：Python 自动生成的字节码缓存，不需要版本控制。
- 模型权重（`.pt`、`.pkl`）：文件太大（几百 MB），GitHub 不适合存大文件，且可以通过代码重新训练生成。

# 面试题整理

## Day 4：PyTorch Autograd + LLM Prompt

### Q1：PyTorch 的 grad 为什么会累加？
**答**：默认累加是为了支持梯度累积（大 batch 训练）和多任务学习。
标准三步：optimizer.zero_grad() → loss.backward() → optimizer.step()

### Q2：为什么 System Prompt 比 User Prompt 控制力强？
**答**：System 位于序列前端，在 Transformer 多层 Attention 中反复传播，
持续影响后续所有 token 的条件概率分布。

### Q3：Few-shot Prompt 为什么有效？
**答**：不是模型"理解"了规则，而是 Few-shot 例子提供了条件概率的锚点，
诱导模型进入训练数据中相似的模式区域。

### Q4：Sigmoid 为什么不适合多分类？
**答**：Sigmoid 输出独立概率，各类概率之和不为 1。多分类用 Softmax，
它通过指数归一化保证概率和为 1，且放大差异。

### Q5：L1 和 L2 正则化的几何区别？
**答**：L1 约束是菱形（顶点在坐标轴），最优解容易落在顶点 → 稀疏。
L2 约束是圆形，最优解在边界任意位置 → 权重平滑小。
 
## Day 5：PyTorch nn.Module + 反向传播

### Q1：nn.Module 的 `__init__` 和 `forward` 分别做什么？为什么必须继承 nn.Module？
**答**：`__init__` 定义网络结构（层），`forward` 定义前向计算流程。继承 nn.Module 后，PyTorch 会自动追踪所有 `nn.Parameter`，支持 `model.parameters()` 传给优化器，自动管理 GPU 搬运和状态保存。

### Q2：`model.train()` 和 `model.eval()` 有什么区别？忘记调用会怎样？
**答**：`train()` 启用 Dropout（随机丢弃神经元）和 BatchNorm 使用批次统计量；`eval()` 关闭 Dropout，BatchNorm 使用全局统计量。如果测试时忘记 `eval()`，Dropout 会随机丢弃神经元，导致同一输入每次预测结果不同，准确率暴跌。

### Q3：CrossEntropyLoss 的输入需要经过 softmax 吗？为什么？
**答**：不需要。`nn.CrossEntropyLoss` 内部已经集成了 `LogSoftmax + NLLLoss`，数值稳定性更好。如果先手动 softmax 再传进去，会导致对数概率经过两次 log/exp，数值不稳定且结果错误。

### Q4：什么是梯度消失？Sigmoid 为什么会导致梯度消失？ReLU 为什么能缓解？
**答**：反向传播时，梯度从输出层向输入层逐层传递，每经过一层要乘以该层的局部导数。Sigmoid 的导数最大值为 0.25，多层连乘后梯度指数级衰减到接近 0，前面几层几乎不更新。ReLU 在正区间的导数为 1，梯度可以无损传递，缓解了消失问题。

### Q5：momentum（动量）在 SGD 中的作用是什么？
**答**：模拟物理中的动量概念。更新参数时不仅考虑当前梯度，还累积之前梯度的指数加权平均。作用：1）加速收敛（在一致方向上积累速度）；2）抑制震荡（抵消垂直于最优方向的噪声）。
